# 운동 기록 앱 설계 문서

**작성일**: 2026-05-07  
**프로젝트**: 매일 운동 내역 기록하는 웹 서비스

## 개요

이 프로젝트는 사용자가 매일의 운동 내역(운동 종류, 운동 시간)을 기록하고, 캘린더 형식으로 시각화하며, 주간/월간 통계를 볼 수 있는 웹 애플리케이션입니다.

## 핵심 요구사항

### 기능
- **회원가입/로그인**: Firebase Authentication으로 이메일/비번 기반 인증
- **운동 기록**: 날짜별로 여러 운동 기록 가능 (운동 종류 + 시간)
- **캘린더 뷰**: GitHub 잔디심기 스타일의 히트맵으로 운동한 날 시각화
- **모달**: 날짜 클릭 시 그날의 운동 기록 상세 보기/추가/수정/삭제
- **통계**: 주간/월간 총 시간, 평균 시간, 운동한 날 수
- **네비게이션**: 이전/다음 버튼으로 월 단위 이동

### 기술 스택
- **프론트엔드**: Next.js, TailwindCSS
- **백엔드**: Firebase (Firestore + Authentication)
- **배포**: Vercel
- **브라우저 지원**: 모바일 + 데스크톱

### 제약사항
- 백엔드 코드 없음 (Firebase만 사용)
- 회원가입 필수 (로그인하지 않으면 접근 불가)
- 사용자별 독립적인 데이터 저장

## 페이지 구조

### 1. 회원가입/로그인 페이지
사용자가 처음 방문했을 때 보는 페이지

**레이아웃**:
- 앱 제목/로고
- 이메일 입력 필드
- 비밀번호 입력 필드
- "회원가입" 버튼
- "로그인" 버튼 (기존 사용자)
- 에러 메시지 영역 (입력 오류, 네트워크 오류 등)

**동작**:
- 회원가입: Firebase에 새 사용자 생성
- 로그인: Firebase로 인증 후 메인 페이지로 이동
- 에러 처리: 비번 형식, 이미 존재하는 이메일 등

---

### 2. 메인 페이지 (로그인 후)

**레이아웃** (세로):
```
┌─────────────────────────────┐
│  [앱제목]      [로그아웃 ✕]  │  <- 헤더
├─────────────────────────────┤
│                             │
│  이번주 4일 운동했어요 💪   │  <- 주간 운동 요약
│  [운동 기록하기] [통계 보기] │  <- 버튼
│                             │
├─────────────────────────────┤
│                             │
│   2024년 5월                │
│  [◀]          [▶]           │  <- 월 네비게이션
│                             │
│  캘린더 히트맵              │
│  (운동한 날: 초록색)        │
│                             │
└─────────────────────────────┘
```

**캘린더 히트맵**:
- GitHub 잔디심기처럼 7행 × 주 단위 그리드
- 운동한 날: 초록색 (하루에 여러 운동이 있어도 초록색 하나)
- 운동 안 한 날: 흰색/회색
- 셀 클릭: 모달로 그날의 운동 기록 표시
- 색상 강도 옵션: 운동 시간이 많을수록 짙은 초록색 (선택사항)

**"운동 기록하기" 버튼**:
- 클릭 시 "오늘" 날짜로 운동 추가 모달 열기

**"통계 보기" 링크**:
- 통계 페이지로 이동

---

### 3. 운동 기록 추가/수정 모달

**모달이 열리는 시점**:
1. "운동 기록하기" 버튼 클릭 (오늘 날짜)
2. 캘린더의 날짜 셀 클릭
3. 기존 기록의 "수정" 버튼 클릭

**레이아웃**:
```
┌─────────────────────────────┐
│  2024년 5월 15일    [✕]     │  <- 헤더
├─────────────────────────────┤
│                             │
│  운동 기록                  │
│  ─────────────────────────  │
│                             │
│  오늘의 운동 목록:          │
│  • 헬스 60분      [수정][삭제] │
│  • 조깅 30분      [수정][삭제] │
│                             │
│  ─────────────────────────  │
│                             │
│  새로운 운동 추가:          │
│  운동 종류: [드롭다운]      │
│  운동 시간: [숫자 입력] 분  │
│  [추가하기]                 │
│                             │
└─────────────────────────────┘
```

**운동 종류 목록** (13가지):
요가, 헬스, 조깅, 수영, 자전거, 산책, 줄넘기, 스트레칭, 등산, 런닝머신, 계단, 댄스, 스포츠 (기타)

**동작**:
- 기존 기록: 수정/삭제 버튼
- 새 운동 추가: 드롭다운에서 종류 선택 → 시간 입력 → 추가
- 모달 닫기: [✕] 버튼 또는 배경 클릭

---

### 4. 통계 페이지

**레이아웃**:
```
┌─────────────────────────────┐
│  통계         [← 돌아가기]   │  <- 헤더
├─────────────────────────────┤
│                             │
│  📊 주간 통계               │
│  ─────────────────────────  │
│  [막대 그래프]              │  <- 요일별 운동 시간
│  (월 화 수 목 금 토 일)     │
│                             │
│  요약:                      │
│  • 운동 일수: 4일          │
│  • 총 시간: 250분          │
│  • 평균: 62.5분            │
│                             │
│  📊 월간 통계               │
│  ─────────────────────────  │
│  [라인 차트]                │  <- 날짜별 누적 운동 시간
│  (1월~31일)                │
│                             │
│  요약:                      │
│  • 운동 일수: 18일         │
│  • 총 시간: 1,200분        │
│  • 평균: 66.7분            │
│                             │
└─────────────────────────────┘
```

**차트 상세**:
- **주간 통계 (막대 그래프)**:
  - X축: 요일 (월~일)
  - Y축: 운동 시간 (분)
  - 각 막대는 그날의 총 운동 시간
  - 색상: TailwindCSS 초록색 계열

- **월간 통계 (라인 차트)**:
  - X축: 날짜 (1~31)
  - Y축: 누적 운동 시간 (분)
  - 누적 그래프로 월간 진행 상황 시각화
  - 색상: TailwindCSS 초록색 계열

**차트 라이브러리**: Recharts (Next.js와 호환성 좋음)

**통계 항목**:
- **주간 통계**: 현재 주(월~일) 기준
- **월간 통계**: 현재 월 기준

## 데이터 모델

### Firestore 구조

```
users/
  ├── {userId}/
  │   ├── email: string
  │   ├── createdAt: timestamp
  │   └── exercises/
  │       ├── {exerciseId}/
  │       │   ├── date: string (YYYY-MM-DD)
  │       │   ├── type: string (요가, 헬스, ...)
  │       │   ├── duration: number (분 단위)
  │       │   ├── createdAt: timestamp
  │       │   └── updatedAt: timestamp
```

**필드 설명**:
- `date`: ISO 8601 형식 (2026-05-07)
- `type`: 13가지 운동 종류 중 하나
- `duration`: 1 이상의 정수
- `createdAt`, `updatedAt`: Firebase timestamp
